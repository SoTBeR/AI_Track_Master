# Build the LUFS reference set (EBU Tech 3341/3342 signals and expected values)

## Goal

Reference signals and expected values for checking LUFS, LRA and true peak, independent of the Rust code,
for the M0 LoudnessMeter pilot (M0-19) and the M1 acceptance.

## Scope

- In: spec `docs/spec/loudness-reference.md`; generators in `reference/` that build the EBU Tech 3341 and 3342
  test cases that are analytically described in the documents (at least the M0-19 subset); a download script
  for cases that need EBU's original files, with pinned URLs and SHA-256 checksums; a pyloudnorm-based
  measurement module; a machine-readable expected-values file (case id, expected value, tolerance, source clause,
  `generated` or `downloaded`); pytest tests that check pyloudnorm against the expected values published in the
  EBU documents; `CHANGELOG.md` entry.
- Out: committing any EBU file or generated audio; Rust implementation (M0-19); full M1 acceptance run.

## Acceptance criteria

- [ ] Reference files for LUFS checks exist (PLAN section 14 item 5).
- [ ] Expected values and tolerances are taken from the standards, cited by document version and clause:
      ITU-R BS.1770 (current revision), EBU Tech 3341, EBU Tech 3342, EBU R 128 (PLAN section 4 row "Громкость";
      section 9 M1 acceptance).
- [ ] pyloudnorm is cross-checked against the standard's expected values; any disagreement is reported as a
      finding, not hidden by widening tolerances.
- [ ] No EBU test files and no generated audio are committed; analytically described cases are regenerated by
      the tests (same cache rule as M0-15).
- [ ] Cases that need EBU's original files are fetched only by the download script; the script verifies the
      pinned SHA-256 and fails loudly on mismatch; tests for those cases are skipped with an explicit reason
      when the files are absent (a skip, not a pass), and the skip is visible in the pytest summary.
- [ ] True-peak expected values follow BS.1770 Annex 2 (oversampled true-peak) as cited in the spec.
- [ ] pytest and ruff green in CI; pyloudnorm reviewed by dependency-auditor and allowed by ADR-0003.
- [ ] `CHANGELOG.md` "Unreleased" updated.
